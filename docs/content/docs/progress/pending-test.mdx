# 待测试

- 提示词搜索防抖：在提示词中心和画布提示词选择弹窗连续输入关键词，确认停止输入约 300ms 后再发起查询，筛选结果与个人提示词仍正常显示。

- KKAI `gpt-image-2` 参数：分别验证文生图和单图/多图编辑，请求固定使用 `response_format=url`、单次 `n=1`，多张生成按顺序请求；自动质量显式传 `auto`，自动尺寸回落 `1024x1024`，多参考图使用 `image[0]`、`image[1]`，上游返回 base64 或非 HTTP(S) URL 时应明确报错。

- Studio 配色调整：分别检查浅色和深色模式下石墨背景、雾青主操作色、琥珀焦点色在首页、生成工作台、内容库、配置页、Agent 抽屉和画布节点/工具栏中的对比度与状态辨识度。

- 双 UI 工作室风格：在顶栏或配置偏好中切换「原版 / 工作室」，验证切换无需刷新且刷新后仍保留；分别检查浅色和深色模式下的首页、画布列表、画布详情、生图、视频、资产、提示词、配置和 Agent 面板，确认 macOS Studio 工作区壳、面板、弹窗、画布节点/工具栏与生成状态均可用；切回原版后确认原有视觉和业务交互恢复。

- Studio 上下文栏交互：分别在主页、画布、图像、视频、提示词、资产和配置模块点击左侧上下文项，确认按钮有选中反馈，并能滚动到目标区块、打开生成记录、切换筛选/设置页签或跳转到关联模块；确认点击不会修改业务数据。

- KKAI Grok Imagine 1.5 Video：选择 `grok-imagine-1.5-video` 后，确认设置面板仅显示 720p、横竖屏和 6/10/12/16/20 秒；分别验证文生视频、单图和多图参考生成，确认请求使用重复的 `input_reference` 字段、成功任务通过鉴权 `/content` 下载视频、失败任务显示接口错误。

- KKAI Seedance 视频模型：确认渠道模型列表显示 `seeddance-1.0`（实际 `video-v1`）、`seeddance-2.0`（实际 `video-v2`）和 `seeddance-2.0-fast`（实际 `video-v2-fast`）；重点验证 `seeddance-2.0` 的多参考图/视频/音频 JSON 请求、上传限制、引用编号、轮询和鉴权内容下载。

- KKAI 渠道升级补齐：使用已有 KKAI 配置重新打开应用或刷新页面，确认三个 Seedance 模型自动出现，且原有模型、API Key 和调用脚本不变。

- macOS Electron 桌面版：在 Apple Silicon Mac 上执行 `desktop/npm run dev` 应同时启动 Vite 和 Electron；执行 `desktop/npm run make` 后应生成可打开的 `.app/.dmg`。验证桌面版刷新和重启后本地配置、画布、素材及生成记录仍保留，图片/视频/音频及画布 ZIP 导入导出正常；手动启动 Canvas Agent 后，桌面版应能连接并执行画布操作。

- 本地 Codex 自动连接：启动本机 Canvas Agent 后分别打开本地网页和 macOS App，确认应用自动发现 `127.0.0.1:17371`、读取令牌并显示「Codex 已连接」；发送一条简单对话确认 Codex 会话可用，关闭 Agent 后确认应用能显示断开状态；从线上站点请求 `/config` 时不得返回 token。

- Electron 桌面版固定本地端口：验证生产版重启后仍使用同一 IndexedDB 数据空间，API 配置、默认模型、画布与素材不因端口变化而丢失。

- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 我的提示词：在提示词中心切换到「我的提示词」，验证新增、编辑、删除和搜索；从提示词库保存后应出现在个人列表、画布左侧提示词面板和提示词选择弹窗中，刷新页面后数据仍保留在本地，Agent 搜索提示词时也应能查到。
- 画布提示词库：不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示向下箭头且新消息不强制打断阅读，点击箭头后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧以主题浅底气泡显示，AI 回复应在左侧保留 Agent 图标并使用开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。
